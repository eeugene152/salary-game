## Этап 1: Базовый прототип (MVP в одном компоненте)

На этом шаге реализована основная бизнес-логика приложения внутри единого компонента `App.tsx` без разбиения на модули и без передачи пропсов.

### Что реализовано и отработано:
1. **Конечный автомат (State Machine) на одном хуке `useState`:**
   - Вместо управления видимости элементов через CSS (`display: none`), интерфейс полностью зависит от текущего состояния: `UI = f(state)`.
   - Состояние строго типизировано через объединение литералов: `type TStep = 'start' | 'fired' | 'smile'`.
2. **Условный рендеринг через оператор `&&`:**
   - В зависимости от значения `step` React отрисовывает только один из трёх экранов:
     - `'start'` — стартовый экран с кнопкой запроса повышения.
     - `'fired'` — экран отказа («Вы уволены!») с двумя вариантами ответа.
     - `'smile'` — финальный экран со смайлом и кнопкой выхода.
3. **Обработка событий (`onClick`):**
   - Переходы между экранами реализованы через передачу стрелочных колбэков `onClick={() => setStep('...')}`, чтобы предотвратить мгновенный вызов сеттера при рендере страницы.

### Ограничения текущей версии (причина будущего рефакторинга):
- Весь код и разметка находятся в одном файле `App.tsx`.
- Экран `'fired'` сейчас реализован как обычный `div` в потоке документа, а не как полноценное модальное окно поверх страницы с затемнением фона и закрытием по клавише `Escape`.
